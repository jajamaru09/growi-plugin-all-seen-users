# growi-plugin-all-seen-users

GROWIのサイドバーに「閲覧者一覧」ボタンを追加するプラグインです。ボタンをクリックすると、現在閲覧中のページを過去に閲覧したユーザーの一覧をモーダルで表示します。

## 機能

- **サイドバー統合**: 既存のページアクセサリーボタン群に自然に統合
- **閲覧者一覧表示**: ページの閲覧履歴に基づくユーザー一覧
- **レスポンシブデザイン**: デスクトップとモバイルに対応したUI
- **編集モード対応**: 編集モード中は自動的にボタンを非表示
- **SPA対応**: ページ遷移を自動検知してモーダルをクローズ

## 技術仕様

- **フレームワーク**: React 18 + TypeScript
- **ビルドツール**: Vite
- **プラグインSDK**: @growi/pluginkit
- **対応GROWI**: プラグインスキーマバージョン4

## 開発

```bash
# 依存関係インストール
npm install

# 開発サーバー起動
npm run dev

# ビルド
npm run build

# ビルド監視
npm run build:watch
```

## インストール

1. プラグインをビルドしてdistディレクトリを生成
2. GROWIの管理画面からプラグインとして登録
3. プラグインを有効化
